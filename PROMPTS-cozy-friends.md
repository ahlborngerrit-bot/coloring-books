## How to bake

1. One prompt = one page. Do not stack two scenes.
2. If lines go grey: raise LoRA strength, add `pure black lines` and `no grey`.
3. If the page fills with detail: add `nursery level complexity, 3 to 4 elements maximum`.
4. Name the files `cozy-01.png` … `cozy-24.png` and drop them in chat or Drive as images.

## What I cannot do from Grok Projects UI

Creating a Grok Project named “colouring books” and moving the “cozy friends” chat has to be done in the Grok app: New Project → name it → move / add chats. This file is the durable copy of the prompt work.
